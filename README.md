# Tic-Tac-Toe Game with Python

## Project Description
This project is a simple Tic-Tac-Toe game developed using Python as part of a team programming project.

The game allows two players to play against each other on a 3×3 board. Players take turns placing X and O on the board. The game checks for a winner or a tie.

## Technologies Used
- Python
- Tkinter
- Messagebox

## Main Features
- Graphical user interface (GUI)
- Two-player gameplay
- Alternating turns between X and O
- Automatic winner detection
- Tie detection
- Popup messages to display the game result

## How to Run the Project
1. Make sure Python is installed on your computer.
2. Download the `tic_tac_toe.py` file.
3. Open a terminal or command prompt in the project folder.
4. Run the following command:

```bash
python tic_tac_toe.py
```
